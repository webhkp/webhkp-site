## Overview

ToolNatic collects the small utilities developers reach for every day, like JSON formatting, Base64 and JWT decoding, regex testing, hash generation and timestamp conversion, into one fast, distraction-free site.

## The challenge

Most online tools are slow, ad-heavy and quietly send your data to a server. Pasting a production token or customer payload into one of them is a real risk.

## Approach

- **Client-side only**: every tool runs in the browser, with heavier work offloaded to WebAssembly.
- **Instant navigation** with a keyboard-first command bar.
- **Static-first architecture** served from the edge for near-zero running cost.
- **Consistent UI kit** so new tools can be added in an afternoon.

## Outcome

A growing toolbox that loads instantly, works offline and never sees your data.
